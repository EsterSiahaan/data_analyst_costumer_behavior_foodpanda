# 🍔 Foodpanda Customer Behavior Analysis

## 📌 Project Overview

This project analyzes **Foodpanda customer behavior** using SQL and Power BI to uncover purchasing patterns, customer characteristics, restaurant performance, sales trends, and business insights that can support data-driven decision making.

The analysis focuses on exploring customer transactions and identifying factors related to customer spending, loyalty, payment preferences, product popularity, and revenue distribution across different cities.

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Identify top-performing food categories and menu items.
* Measure customer spending and ordering frequency.
* Analyze customer churn distribution.
* Evaluate restaurant ratings and delivery performance.
* Identify monthly sales trends and payment preferences.
* Provide business insights through interactive dashboards.

---

## 📊 Dataset Information

The dataset contains customer transaction data from a Foodpanda food delivery platform simulation, including:

* Customer Information
* Restaurant Information
* Food Categories
* Order History
* Payment Methods
* Ratings
* Delivery Status
* Loyalty Points
* Churn Status
* Sales Transactions

The dataset is designed for customer behavior analysis and exploratory data analysis (EDA).
